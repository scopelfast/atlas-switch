# E8.14 — Zapier / Make com webhooks Taskflow (E8.5)

## Objectivo

Permitir integrações **low-code** (Zapier, Make, n8n, etc.) como alternativa a código próprio, reutilizando os **webhooks outbound** já existentes, com **documentação**, **URL assinada** para obter um JSON de exemplo e **limites** do MVP.

## Fluxo recomendado (catch URL)

1. No Zapier: **Webhooks by Zapier** → **Catch Hook** (ou equivalente no Make: módulo **Webhooks** → **Custom webhook**).
2. Copie a URL `https://hooks.zapier.com/...` ou `https://hook.eu2.make.com/...`.
3. No Atlas: Taskflow → **Webhooks outbound** → crie um webhook com essa URL, eventos `task.created,task.updated` e, se quiser validar origem no Zapier, um **segredo** partilhado (HMAC no cabeçalho `X-Atlas-Webhook-Signature`, ver `Projeto/E8.5-webhooks-taskflow.md`).
4. Crie ou edite uma tarefa: o Atlas faz **POST** `application/json` para a URL; o Zapier/Make recebe o corpo e encadeia os passos seguintes (Slack, Sheets, e-mail, etc.).

## JSON de exemplo (URL assinada)

Para mapear campos sem esperar pelo primeiro evento real:

1. No Taskflow (perfil com permissão de configurar o quadro), use **Gerar URL de exemplo** no cartão de webhooks.
2. Abra a URL gerada (válida **24 horas**) ou use-a num pedido **GET** server-side (Make HTTP, script interno). A resposta é um **exemplo estático** com a mesma forma que o webhook real (`event`, `teamId`, `task`, `sentAt`).
3. **Não partilhe** a URL publicamente: quem a tiver pode ler o nome do time e o modelo de payload (não inclui dados reais de tarefas).

## Limites e anti-abuso (MVP)

- **Máximo 5 webhooks por time** — igual a E8.5 (`TASKFLOW_WEBHOOK_MAX_PER_TEAM`).
- **HTTPS obrigatório** e bloqueio básico SSRF nas URLs de destino (E8.5).
- **Rate limit** no `GET` do exemplo por endereço IP (ver implementação em `lib/taskflow/webhook-sample-rate-limit.ts`).
- **Limites por plano SaaS:** fora do MVP; documentar como evolução no memorial.

## OAuth / app público Zapier

Não há app Atlas publicado na galeria Zapier neste MVP. A integração é **URL + JSON** (padrão universal). OAuth para app de marca é evolução comercial.
